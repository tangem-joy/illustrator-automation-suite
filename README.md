## 🌟 Overview

**Automation Suite Pro** speeds up repetitive vector workflows, fixes common microstock submission rejection issues (Adobe Stock, Freepik, Shutterstock, Vecteezy), standardizes artboards, and packages icons effortlessly.

Available both as a **dockable CEP Extension Panel** and a **Standalone JSX Script**.

---

## 🚀 Core Modules

### 1. 🛡️ Quality Solve (Stock Vector Fixer & Splitter)
- **Purge Stray Elements**: Removes rogue anchor points, unpainted ghost paths, and empty masks/clipping groups.
- **Text Outliner**: Automatically expands and outlines all live fonts to avoid missing font rejections.
- **Smart Splitting**: Preserves exact artboard geometry or auto-splits multi-icon sheets into individual, centered vector files.

### 2. 🪄 BG Remove (Vector & Image Background Cleaner)
- Instant one-click background cleanup.
- Precision color-tolerance control for clean vector separations.

### 3. 📐 Auto Page Resizer (Canvas Standardizer)
- One-click artboard standardization:
  - **Landscape**: 4000 × 2663 px
  - **Square**: 4000 × 4000 px
  - **Banner**: 1000 × 350 px
  - **Custom Dimensions**: With intelligent 88% safe-margin vector scaling.

### 4. 🧩 Icon Set Maker Pro (Grid Packager)
- Rapidly organizes and packages hundreds of standalone icons into uniform, structured vector grid sheets with zero data loss.

## 📥 Installation & Setup

### Option A: CEP Extension Panel (Recommended)
1. Right-click **`⚡ 1-Click Installer.bat`** and select **Run as administrator**.
2. Launch or restart **Adobe Illustrator**.
3. Open from the top menu:
   ```text
   Window ➔ Extensions ➔ Automation Suite Pro
   ```
4. Enter your License Key and click **Activate**.

### Option B: Standalone Script (Zero Installation)
1. Open **Adobe Illustrator**.
2. Go to: **`File` ➔ `Scripts` ➔ `Other Script...`** (`Ctrl + F12`).
3. Select `AI_Automation_Suite_Standalone.jsx` from the `2. Standalone Script` directory.
4. Enter your License Key to run.
