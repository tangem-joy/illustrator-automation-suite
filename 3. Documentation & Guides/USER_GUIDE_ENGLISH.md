## 🚀 Installation & Usage Methods

### Method 1: As a CEP Extension Panel (Recommended)
1. Right-click **`⚡ 1-Click Installer.bat`** (or `INSTALL.bat` inside `1. CEP Extension`) and select **"Run as administrator"**.
2. Launch or restart **Adobe Illustrator**.
3. Navigate to top menu: **`Window` ➔ `Extensions` ➔ `Automation Suite Pro`**.
4. Enter your License Key and click **Activate**!

---

### Method 2: As a Standalone Script (Zero Installation)
1. Open **Adobe Illustrator**.
2. Go to: **`File` ➔ `Scripts` ➔ `Other Script...`** (Shortcut: `Ctrl + F12`).
3. Select **`AI_Automation_Suite_Standalone.jsx`** (or `.jsxbin`) from the **`2. Standalone Script`** folder.
4. Enter your license key and enjoy!

## 🔑 Licensing & Hardware ID Policy
* **1 License per Computer:** Each license key binds securely to your machine's hardware ID.
* **Device Transfer / Deactivation:**
  - You can release your license at any time by clicking **"License Details"** ➔ **"Deactivate License"** before changing computers or upgrading hardware.
  - Deactivated keys can be re-activated seamlessly.

## 🛠️ Troubleshooting
* **Panel not visible:** Make sure to fully restart Adobe Illustrator after running the installer.
* **Administrator Rights:** Always ensure the installer is executed with Administrator privileges.
* **Active Internet:** An active internet connection is required during license verification and activation.
