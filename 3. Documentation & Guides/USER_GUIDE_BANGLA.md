# ⚡ Automation Suite Pro v2.7 — ব্যবহার নির্দেশিকা (User Manual)

**JoyNest Agency**-এর প্রিমিয়াম অ্যাডোবি ইলাস্ট্রেটর অটোমেশন স্যুট ব্যবহারের জন্য আপনাকে ধন্যবাদ! এই সফটওয়্যারের মাধ্যমে আপনি আপনার ভেক্টর গ্রাফিক্স, অ্যাডোবি স্টক ভেক্টর ক্লিনিং, ব্যাকগ্রাউন্ড রিমুভাল, ক্যানভাস রিসাইজিং এবং আইকন গ্রিড শিট তৈরি করার কাজ নিমিষেই সম্পন্ন করতে পারবেন।

---

## 🌟 প্যাকেজের অন্তর্ভুক্ত প্রধান ৪টি টুল:
1. **🛡️ Quality Solve (Adobe Stock Fixer & Multi-Icon Splitter):** 
   - 0-এরিয়া পয়েন্ট, আইসোলেটেড পয়েন্ট, ঘোস্ট পাথ ও টেক্সট অটোমেটিক আউটলাইনে রূপান্তর করে স্টক সাইট কমপ্লায়েন্ট তৈরি করে।
   - আর্টবোর্ড সাইজ অপরিবর্তিত রেখে বা একাধিক আইকন অটো-স্প্লিট করে আলাদা ফাইলে সেভ করার সুবিধা।
2. **🪄 BG Remove (Background Cleaner):**
   - ভেক্টর বা রাস্টার ইমেজ থেকে অবাঞ্ছিত ব্যাকগ্রাউন্ড ও কম্পাউন্ড পাথ এক ক্লিকে রিমুভ করে।
3. **📐 Auto Page Resizer (Canvas Standardizer):**
   - 4000×2663 (Landscape), 1000×350 (Banner), 4000×4000 (Square) বা কাস্টম ডাইমেনশনে ৮৮% সেফ মার্জিনসহ সেন্টারিং ও স্কেলিং।
4. **🧩 Icon Set Maker Pro (Vector Grid Sheet Maker):**
   - শত শত ভেক্টর আইকনকে অটোমেটিক সুন্দর গ্রিড শিটে (৫×৩, ৫×২, ৪×৩) হাই-স্পিডে প্যাকেজিং করে।

## 🚀 ইনস্টলেশন ও ব্যবহার পদ্ধতি (২টি সহজ উপায়)

### উপায় ১: CEP Extension Panel হিসেবে (সর্বোচ্চ রেকমেন্ডেড)
1. **`⚡ 1-Click Installer.bat`** ফাইলটিতে রাইট-ক্লিক করে **"Run as administrator"** সিলেক্ট করুন।
2. ইনস্টলেশন সম্পন্ন হলে **Adobe Illustrator** চালু করুন (যদি খোলা থাকে তবে বন্ধ করে পুনরায় ওপেন করুন)।
3. ইলাস্ট্রেটরের ওপরের মেনুবার থেকে যান: **`Window` ➔ `Extensions` ➔ `Automation Suite Pro`**।
4. প্যানেলটি ওপেন হলে আপনার **License Key** দিয়ে **Activate** বাটনে ক্লিক করুন।

---

### উপায় ২: Standalone Script হিসেবে (কোনো ইনস্টলেশন ছাড়াই)
1. **Adobe Illustrator** চালু করুন।
2. ইলাস্ট্রেটরের মেনু থেকে যান: **`File` ➔ `Scripts` ➔ `Other Script...`** (শর্টকাট: `Ctrl + F12`)।
3. **`2. Standalone Script`** ফোল্ডারে থাকা **`AI_Automation_Suite_Standalone.jsx`** (অথবা `.jsxbin`) ফাইলটি সিলেক্ট করে রান করুন।
4. লাইসেন্স কি প্রবেশ করিয়ে কাজ শুরু করুন।

---

## 🔑 লাইসেন্স অ্যাক্টিভেশন ও ডিভাইস পরিবর্তন নিয়মাবলী

* **১টি লাইসেন্স = ১টি ডিভাইস:** প্রতিটি লাইসেন্স কি একটি নির্দিষ্ট কম্পিউটারের সাথে নিরাপদভাবে যুক্ত হয়।
* **লাইসেন্স ডিঅ্যাক্টিভেট ও ডিভাইস ট্রান্সফার:**
  - আপনি যদি কম্পিউটার পরিবর্তন বা উইন্ডোজ রি-ইনস্টল করতে চান, তবে প্যানেলের **"License Details"** ➔ **"Deactivate License"** বাটনে ক্লিক করে লাইসেন্সটি আনলিংক করতে পারবেন।
  - একবার ডিঅ্যাক্টিভেট করার পর আপনার লাইসেন্সটি পুনরায় ব্যবহারযোগ্য হবে।
* **সাপোর্ট ও রিনিউয়াল:** লাইসেন্স কি সংক্রান্ত যেকোনো সহায়তার জন্য আপনার সার্ভিস প্রোভাইডারের সাথে যোগাযোগ করুন।

## ⚠️ সাধারণ সমাধান (Troubleshooting):
* **"Extension not showing under Window > Extensions":** ইনস্টলার রান করার পর অবশ্যই Illustrator সম্পূর্ণ রিস্টার্ট দিতে হবে।
* **"Run as Administrator":** ইনস্টলার ফাইল রান করার সময় উইন্ডোজ অ্যাডমিনিস্ট্রেটর পারমিশন দিতে হবে।
* **"Internet Connection":** প্রথমবার লাইসেন্স অ্যাক্টিভেশনের সময় একটিভ ইন্টারনেট কানেকশন থাকা প্রয়োজন।
