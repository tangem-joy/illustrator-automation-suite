HOW TO INSTALL & USE:

STEP 1: INSTALLATION (CEP Extension Panel)
------------------------------------------------------------------------
1. Right-click "⚡ 1-Click Installer.bat" and choose "Run as administrator".
2. Wait for the success confirmation window.

STEP 2: LAUNCH IN ILLUSTRATOR
------------------------------------------------------------------------
1. Start (or Restart) Adobe Illustrator.
2. In the top menu bar, click:
   Window > Extensions > Automation Suite Pro

STEP 3: ACTIVATE YOUR LICENSE
------------------------------------------------------------------------
1. When prompted, enter your purchased License Key.
2. Click "Activate".
3. Done! Enjoy high-speed vector automation.

------------------------------------------------------------------------
ALTERNATIVE: RUN AS STANDALONE SCRIPT
------------------------------------------------------------------------
If you prefer not to install the extension:
In Illustrator, go to: File > Scripts > Other Script (Ctrl+F12)
Select "AI_Automation_Suite_Standalone.jsx" from folder "2. Standalone Script".

For detailed documentation, please check "3. Documentation & Guides".
